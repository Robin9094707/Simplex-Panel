Simplex Wing 1.0.0 is the public Simplex Panel Community Edition for iOS and iPadOS 26+.

- Native server workspace with multiple Pterodactyl panels, English/German first-run setup and customizable dashboards.
- Live console, resource history, files and transfers, backups, schedules, databases, allocations, subusers, startup and account security.
- Local-JAR Minecraft plugin/mod management, metadata checks, verified uploads and mod rollback backups. No marketplace APIs.
- Widgets and foreground-updated Live Activities, with timestamps and signing-aware shared storage.
- Separate app identity: `eu.simplexsmp.wing`.

The IPA is **unsigned** and requires signing before installation. Widget sharing depends on signing entitlements. Host-specific API access and physical-device behavior are not certified by the simulator checks. Read the README and signing guide before installing.
