# Getting started

1. Install the signed app on an iPhone or iPad running iOS/iPadOS 26 or later.
2. Choose **English** or **Deutsch** in the welcome sheet.
3. In your hosting panel, open **Account → API Credentials** and create a **Client API key**. Keep IP restrictions compatible with your mobile connection.
4. In Simplex Wing, enter a name, the HTTPS panel URL and the key. A panel in a subdirectory is supported. Do not use your provider's billing portal or Wings node URL.
5. The app checks the server list before saving a connection. Add other panels using the panel switcher.

Keys are stored in the device keychain. The app never needs an Application key or panel administrator privileges. Server owners can grant subusers the permissions they need.

Open a server for its overview, console and file workspace. **More** contains backups, management and Live Activity settings. Enable Minecraft tools only on Minecraft servers; the switch is available on the overview.

Change language, appearance, lock settings and saved panels under Settings. Removing a connection deletes its local key and widget access without deleting the server.

The demo has synthetic data and does not send mutations to real servers. It is useful for learning the interface before connecting.
